# ADR 0015 — Translation and selected element flow

Status: accepted for the owner-requested inspector simplification.

The primary panel presents Japanese-to-Vietnamese translation and a bounded source-backed flow summary. Full technical findings, filters and metadata remain available in a collapsed disclosure. The shared browser UI applies to the four existing authorized integrations; no new framework or runtime observation is introduced.

Add a `value` static detail and inspector group for display expressions and bounded lexical declaration snippets. JSX and original Vue template evidence feed the existing worker, privacy checks, transport and persistent-cache validation. Bump static cache identity and selected AI explanation identity so older results cannot conceal the new projection or reuse the former explanation prompt. No database migration is required.

Keep rendering guards on the selected subject separate from guards on reachable handler actions. Attach action guards to their outcomes. Include native anchor source destinations and retain uncertainty for dynamic expressions. Source references never establish actual execution, effective visibility, current values, or successful navigation.

Value provenance is limited to lexical declarations: it does not claim complete API-to-state tracking, parent-component dataflow, CSS computation, delegated events or server execution. Optional AI receives the existing guarded evidence contract and a concise testing-oriented question; it receives no DOM values or expanded source-read capability. Existing read-only enforcement and explicit consent remain required.
